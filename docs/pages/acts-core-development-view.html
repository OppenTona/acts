ACTS Core — Development View (4+1)

The development view describes how ACTS organises source code under Core/. This 4+1 view focuses on module structure and packaging at implementation level.

  • Main library: ActsCore (declared in Core/CMakeLists.txt).
  • Source code: Core/src/* with public headers in Core/include/Acts/*.
  • Scope: Core modules only, excluding Plugins/Fatras/Examples.
